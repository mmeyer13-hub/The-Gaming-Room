# The-Gaming-Room
For The Gaming Room project, an object-oriented software design was created to expand Draw It or Lose It into a multi-platform web application. Using Singleton and Iterator patterns for game state management and entity lookups, the architecture ensured scalability, secure data handling, and cross-platform competitive gameplay.

For The Gaming Room project, the client wanted to expand their Android-exclusive Draw It or Lose It game into a scalable, multi-platform web application supporting multi-user competitive gameplay. To accomplish this, the design documentation successfully outlined a robust, object-oriented architecture utilizing a Singleton pattern for centralized game state management, an Iterator pattern for efficient entity lookups, and a structured class hierarchy governing unique identifiers and naming constraints for games, teams, and players. Developing this documentation was particularly helpful because it served as a clear, structured blueprint that resolved architectural and implementation decisions beforehand, which significantly minimized rework and debugging during coding. While the structural design was strong, the documentation could be improved by adding explicit sequence diagrams to better visualize real-time client-server interactions. Ultimately, user needs were effectively interpreted by translating the desire for broader accessibility and scalability into concrete technical requirements—such as cloud hosting, cross-platform compatibility, and strict entity uniqueness—highlighting how crucial it is to align technical software design with real-world user workflows and performance demands. Moving forward, software design should be approached methodically from the top down, prioritizing early stakeholder alignment, modular object-oriented principles, and robust security planning from the start.
